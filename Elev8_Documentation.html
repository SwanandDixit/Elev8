Section 1

Problem Statement

India's blue-collar workforce — comprising electricians, plumbers, carpenters, cooks, cleaners, drivers, security guards, painters, welders, and masons — constitutes over 500 million workers. Despite being the backbone of the Indian economy, this workforce faces severe systemic challenges in accessing dignified, fair, and direct employment opportunities.

💸 Exploitative Middlemen

Local labour contractors and agents charge 40–60% commission from workers' earnings. Workers have no transparency on pay, no contracts, and no recourse.

🌐 Language Exclusion

All major employment platforms in India are built exclusively in English, effectively barring 400M+ Hindi and Marathi-speaking workers from digital job discovery.

🔒 No Trust Infrastructure

Employers cannot verify worker credentials, skills, or background. This lack of trust leads to lower wages, exploitation, and hesitation in hiring.

🏠 Household Gap

Millions of household employers (needing maids, cooks, drivers) have no safe, reliable digital platform. They rely entirely on word-of-mouth or risky classifieds.

Root Cause: The Indian digital employment ecosystem is designed for white-collar workers. Blue-collar workers have been systematically ignored, creating a massive opportunity gap.
Section 2

Proposed Solution — Elev8

Elev8 is a production-ready, full-stack, multilingual employment platform built specifically for India's blue-collar workforce. It addresses every identified problem simultaneously through thoughtful design and engineering.

🌐 Multilingual First

English, हिंदी, मराठी — instant switching, no page reload. Devanagari typography fully rendered.

🛡️ Skill Verification

Partner certificates from NSDC, ITI, Udemy + Elev8 practical assessments. Verified badges shown on profiles.

🏠 Dual Posting

Separate flows for Household and Business employers. Address privacy protected for household requirements.

📱 Mobile-First

Works on ₹5,000 Android phones. Bottom navigation, touch-optimized 44px targets, offline demo mode.

🔐 Secure Auth

Supabase + Google OAuth. Role-based access control: Worker / Employer / Admin with protected routes.

⚡ Zero Middlemen

Free direct listing. Workers keep 100% of their earnings. Premium listing for ₹299/month for boosted visibility.

Section 8

Security Implementation

🔐 Row Level Security (RLS)

Every Supabase table has RLS policies. Workers can only read/write their own data. Employers can only see their own listings and applications.

🎫 JWT Authentication

All API requests carry a signed JWT token from Supabase Auth. Tokens expire after 1 hour and are automatically refreshed client-side.

🛡️ Role-Based Access Control

Three roles: Worker, Employer, Admin. Protected routes automatically redirect unauthorized users. Role stored securely in the users table.

🔒 No Credentials in Code

All sensitive keys stored in environment variables (.env). .env is in .gitignore — never committed to source control.

📱 Address Privacy

Household employer addresses are never shown publicly. Contact is only made through the in-app messaging system after connection.

🚨 Content Moderation

UI prevents phone numbers/emails in public job descriptions. Admin panel includes flagged content review queue.

Section 9

Multilingual System

Elev8 is built with language access as a first-class feature, not an afterthought. The internationalization system uses react-i18next with the following architecture:

Three Languages Supported: English (EN), Hindi — हिंदी (HI), Marathi — मराठी (MR)

How It Works

  • Translation JSON files loaded from /public/locales/{language}.json
  • Language detected automatically from browser settings via i18next-browser-languagedetector
  • Selected language persisted across sessions in localStorage
  • Instant toggle via LanguageSwitcher component — zero page reload
  • Devanagari script rendered using Noto Sans Devanagari Google Font
  • Font automatically switches based on active language via CSS :lang(hi) selector

Coverage

All UI text, labels, buttons, error messages, navigation items, form placeholders, and descriptive content are fully translated across all 3 languages. Each translation file contains 200+ keys.

Scalability Plan

Phase 1 — MVP (Current)

Maharashtra-focused launch with core features: job posting, worker profiles, skill verification, and multilingual support. Targeting 10,000 workers and 5,000 employers in the first 6 months.

Phase 2 — Pan-India Expansion

  • Expand to 5 additional languages (Tamil, Telugu, Bengali, Gujarati, Kannada)
  • Launch in 20 major Indian cities
  • Integrate SMS-based job alerts for feature phone users
  • Partner with municipal corporations for migrant worker support

Phase 3 — Platform Ecosystem

  • Elev8 Worker App (Flutter mobile app)
  • AI-powered job matching engine
  • Integrated payroll and UPI-based payment processing
  • Insurance and social security linking for verified workers
  • API for B2B enterprise bulk hiring

Technical Scalability

Database

Supabase (PostgreSQL) with PgBouncer connection pooling handles millions of concurrent connections. Read replicas for high-traffic queries.

Frontend

Stateless React SPA on Netlify CDN — scales infinitely. Code splitting via Vite for faster load times.

Section 12

Real-World Impact

Mission: Every blue-collar worker in India deserves dignified employment, fair pay, recognized skills, and digital identity — regardless of education, language, or location.

💰 Economic Impact

Eliminating middlemen saves workers 40–60% of their earnings. A worker earning ₹500/day retains ₹200–300 more per day — ₹6,000–9,000/month extra income.

📚 Skill Development

Certification system encourages skill upgrading. Verified workers earn 25–40% higher wages. Partnership with NSDC & ITI creates a recognized credential pathway.

🌐 Digital Inclusion

Hindi + Marathi support brings 400M+ speakers into the digital workforce economy for the first time. Mobile-first design ensures access on ₹5,000 phones.

Setup & Installation

Prerequisites

  • Node.js v18.x or higher
  • npm v9.x or higher
  • Git

Installation Steps

# 1. Clone the repository
git clone https://github.com/SwanandDixit/Elev8.git
cd Elev8

# 2. Install dependencies
npm install

# 3. Set up environment variables
cp .env.example .env
# Edit .env with your Supabase credentials
# (App runs in demo mode if no credentials provided)

# 4. Start development server
npm run dev
# Visit: http://localhost:5173

# 5. Build for production
npm run build

Environment Variables

VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
VITE_RAZORPAY_KEY=your_razorpay_key  # optional
💡 Demo Mode: If no Supabase credentials are provided, Elev8 automatically activates Demo Mode — all features remain fully explorable using localStorage-based mock sessions. No backend required.
