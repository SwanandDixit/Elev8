🏆 Hackathon Submission 2024
Elev8

Skill-Based Employment Platform for Blue-Collar Workers in India

Connecting 500M+ skilled workers with dignified, direct, verified employment opportunities — cutting out middlemen, breaking language barriers, building trust.

React + Vite TypeScript Tailwind CSS v4 Supabase Multilingual Mobile-First
The Problem

500M Workers. Zero Digital Identity.

India's blue-collar workforce is the backbone of the economy — yet they remain completely excluded from the digital opportunity landscape.

💸

Exploitative Middlemen

Workers pay 40–60% commission to local agents just to find jobs. No transparency, no accountability.

🌐

Language Barriers

Existing platforms built only in English exclude 400M+ Hindi and Marathi speakers from digital work discovery.

🔒

Zero Trust System

Employers can't verify worker skills or background — leading to hesitation, lower pay, and exploitation.

🏠

Household Employers Ignored

Millions of household employers (maids, cooks, drivers) have no safe digital platform to find verified workers.

Our Solution

Elev8 — One Platform, Everything

🌐

Multilingual First

English, हिंदी, मराठी — instant switching, no reload. Devanagari typography. Language persisted in localStorage.

🛡️

Skill Certification

Partner certs (NSDC, ITI, Udemy) + Elev8 practical assessments. Verified badges build employer trust.

🏠

Household + Business

Dual posting flows. Separate requirement types with address privacy for household employers.

📱

Mobile-First

Works on ₹5,000 Android phones. Bottom nav, touch targets, filter sheets — all optimized for mobile.

🔐

Secure Auth

Supabase + Google OAuth. Role-based access: Worker / Employer / Admin. RLS on every database table.

⚡

Zero Middlemen

Direct connection between worker and employer. Standard listing is free. Premium boost for ₹299.

Platform Features

11 Complete Production-Ready Pages

  • ✅Home — Hero, animated stats counter, categories, testimonials
  • ✅Find Work — Search + filter + sort job listings
  • ✅Browse Workers — Worker directory with availability filter
  • ✅Worker Profile — Full profile, skills, reviews, hire CTA
  • ✅Post Requirement — 3-step posting (Household / Business)
  • ✅Register Worker — 4-step onboarding flow
  • ✅Certifications — Partner certs + Elev8 assessment system
  • ✅About — Mission, values, team, timeline
  • ✅Sign In / Sign Up — Email + Google OAuth, role toggle
  • ✅Worker Dashboard — Applications, matches, profile
  • ✅Employer Dashboard — Listings, applicants
  • ✅Admin Panel — User mgmt, cert queue, moderation
Architecture & Tech Stack

Built for Scale

FRONTEND
React 18 + Vite + TypeScript
Tailwind CSS v4 + Zustand + React Router v6
⬇️
BACKEND
Supabase (PostgreSQL + RLS)
Supabase Auth + Realtime
⬇️
DEPLOYMENT
Vercel Edge Network + CDN
Global low-latency delivery

Scalability

Supabase PgBouncer handles millions of concurrent connections. Stateless frontend scales infinitely on Vercel.

Security

Row Level Security on every table. JWT tokens. No sensitive data in client code.

Performance

Vite code splitting. Lazy-loaded i18n. 169KB gzipped bundle. Fast on 3G networks.

Payments Ready

Razorpay integration ready. Premium listings for ₹299/month. Monetization from day one.
